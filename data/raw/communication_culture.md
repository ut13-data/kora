# Communication Culture & Tone Guidelines

## Purpose

Nexora is a multi-timezone, multi-cultural company. This guidance helps employees —
particularly managers communicating with a team member from a different cultural
background — think about *tone*, not *substance*. The facts, requests, and deadlines
being communicated should never change based on who's receiving them. How they are
*phrased* may reasonably adapt.

## The Four-Layer Framework

KORA (and any employee) should be able to distinguish between four different kinds of
statement:

1. **FACT** — Something objectively true and unchanging regardless of audience.
   *Example: "The security training deadline is 10 working days from start date."*
2. **COMPANY PREFERENCE** — A Nexora-specific standard or expectation, documented in an
   internal policy.
   *Example: "Nexora prefers written follow-up after verbal agreements."*
3. **CULTURAL COMMUNICATION GUIDANCE** — A general tendency observed in a given
   professional/cultural context, offered as guidance, not a rule.
   *Example: "Direct, explicit phrasing is a common workplace tendency in Germany."*
4. **INDIVIDUAL PREFERENCE** — How a specific person actually prefers to communicate,
   which always takes precedence over the cultural guidance layer.

**Individual preference overrides cultural assumption, always.** Cultural tone profiles
(see germany_workplace_tone.md, india_workplace_tone.md, us_workplace_tone.md,
uk_workplace_tone.md, international_communication.md) describe common workplace
tendencies, not rules that apply to every person from that context. They exist to reduce
unintentional friction, not to stereotype colleagues.

## Example: Same Instruction, Different Phrasing

**Neutral:** "Please complete the security training by Friday."

**More direct style (common in some German professional contexts):**
"Please complete the security training by Friday, 18 September."

**More relationship-oriented style (common in some other contexts):**
"Please complete the security training by Friday. Let me know if you need any help
accessing the training."

The underlying instruction — deadline, action required — is identical in both. Only tone
adapts.

## Guidance Language Used Throughout These Documents

Tone-profile documents deliberately use hedged language such as "common workplace
tendency," "may be preferred in some professional contexts," and "individual preferences
vary" — never absolute claims about any nationality, group, or individual.
