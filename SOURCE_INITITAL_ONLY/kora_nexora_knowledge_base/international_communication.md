# International / Neutral Communication Guidance

Used as the default when communicating with a mixed-location group, a customer of
unknown cultural background, or anyone whose individual style you don't yet know.

## Baseline Approach
- State the ask and, if applicable, the deadline explicitly and early in the message —
  this works across every profile described in this document set and avoids relying on
  tone to carry information.
- Avoid idioms, sports metaphors, or culturally specific humor that may not translate.
- When giving feedback to someone whose style you don't know yet, default to a
  moderately direct but warm tone: clear about the issue, clear that it's not personal.
- When in doubt about urgency, say the deadline explicitly rather than assuming tone will
  convey it.

## When Communicating Across Time Zones
- Note the recipient's likely working hours when sending a message outside your own
  hours; mark clearly if something is or isn't expected to be read/actioned same-day.
- Prefer async, written updates (see PROC-HR-003) for anything that doesn't strictly
  need real-time discussion.

## The One Rule That Doesn't Change
Regardless of audience or tone adaptation: the underlying fact, request, or deadline
communicated must always be accurate and identical. Tone adapts; substance does not.
See DOC-COMM-001 for the full FACT / COMPANY PREFERENCE / CULTURAL GUIDANCE / INDIVIDUAL
PREFERENCE framework this is built on.
