# Internal FAQ

**Q: Who approves a discount above 15%?**
A: The Sales Manager, up to 30%. Above 30%, or any multi-year term, requires VP Sales
approval. See PROC-SALES-002.

**Q: I'm a new Data Analyst — how do I get access to the production analytics
environment?**
A: You need explicit approval from the Data & Analytics Manager, then IT provisions
access. It is not automatic even within the Data & Analytics department, because the
warehouse contains customer data. See PROC-IT-001.

**Q: What's the difference between a "client," a "customer," and an "account"?**
A: They mostly overlap but aren't used consistently — see glossary.md, TN-004.

**Q: Who does final go-live sign-off for a customer implementation?**
A: The Implementation Manager (called "Project Lead" in documents from before
2025-03-01 — same role). See PROC-IMPL-001.

**Q: How long do new hires have to complete security training?**
A: 10 working days from start date, per the current policy (PROC-HR-001, v3.0,
effective 2025-06-01). An older archived document said 30 days — that is no longer
current.

**Q: A customer reported a bug on an old, deprecated product configuration — what's the
process?**
A: This is a known documentation gap (PROC-ENG-002, KG-02). Currently handled case-by-case
by the relevant Engineering Manager; no standard process is documented yet.
