# Customer Onboarding Process (Customer Onboarding — see glossary.md TN-002 for
disambiguation from Employee Onboarding)

## Purpose
Move a customer from signed contract to live production usage.

## Steps

1. **Kickoff** — Implementation Consultant reviews the AE's "Deal Closed" handoff record
   and schedules a kickoff call within 5 business days of contract signature.
2. **Discovery** — Consultant confirms configuration requirements (e.g., NexFlow
   batch/lot tracking, NexConnect data sources) directly with the customer.
3. **Configuration & data migration** — Consultant (or Solutions Architect, for custom
   integrations) configures the tenant and migrates initial data.
4. **Training** — Consultant delivers admin and end-user training sessions.
5. **Go-live sign-off** — The **Implementation Manager** provides final go-live approval
   after Consultant confirms all discovery items are resolved.
6. **Handoff to Customer Success** — Implementation Manager and the assigned Customer
   Success Manager hold a formal handoff call; open items are logged in the account
   record.

## Known Gap — KG-01
This process assumes the AE's "Deal Closed" handoff record is complete. It does not
specify what the Implementation Consultant should do if the handoff record is missing
required fields (e.g., agreed go-live date not documented). In practice this causes
kickoff delays; there is no formal fallback procedure.
