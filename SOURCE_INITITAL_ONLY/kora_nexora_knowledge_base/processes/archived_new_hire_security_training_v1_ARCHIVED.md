# New Hire Security Training Requirement (ARCHIVED)

All new hires must complete the mandatory security awareness training module within
**30 days** of their start date.

*This requirement was superseded by PROC-HR-001 Version 3.0 (effective 2025-06-01),
which shortened the requirement to 10 working days. This document is retained for
historical reference only.*
