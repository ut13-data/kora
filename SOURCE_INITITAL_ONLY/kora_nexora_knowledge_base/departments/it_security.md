# IT / Security Department

IT/Security is based in Munich (LOC-MUC) and owns internal systems access, endpoint
security, and company-wide security policy and training.

## Roles

**IT Support Specialist** — Handles employee-facing IT requests: hardware, account
provisioning, software access.

**Security Analyst** — Monitors for security incidents, runs the annual security review,
administers the mandatory security training program.

**IT Manager** — Owns internal systems uptime and IT support SLAs.

**CISO** — Owns company-wide security policy (PROC-IT-002) and is the final decision
authority during a confirmed security incident.

## Note

IT/Security owns *internal* systems access and security policy. Product-level access
control for customer-facing systems (e.g., who inside Nexora can view a customer's
production data) is governed jointly with the relevant product/department — see
PROC-IT-001.
